🎮 Command Line Tic-Tac-Toe Game in C++

A simple two-player Tic-Tac-Toe game developed using C++ as my Semester 1 programming project.

This game runs in the command line and allows two players to play against each other.

✨ Features

* 👥 Two-player gameplay
* 🏆 Win detection
* 🤝 Draw detection
* ✅ Invalid move prevention
* 🔄 Play again option

🛠️ Technologies Used

* C++
* Standard Input/Output
* Loops and conditional statements
* Basic game logic

🚀 How to Run

Requirements

* A C++ compiler, such as GCC or MinGW

Compile the Program

g++ "Tic Tac Toe Game.cpp" -o tictactoe

Run the Game

Windows:

tictactoe.exe

Linux / macOS:

./tictactoe

🎯 How to Play

1. Run the program.
2. Player X and Player O take turns.
3. Choose an available position on the board.
4. Get three marks in a row, column, or diagonal to win.
5. If all positions are filled without a winner, the game ends in a draw.
6. Choose whether to play again.
